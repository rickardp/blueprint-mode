# Blueprint Status

## Steps

1. Glob the Blueprint artifacts in one batch: `docs/specs/*.md`, `docs/specs/features/*.md`, `docs/specs/non-functional/*.md`, `docs/adrs/*.md`, `patterns/good/*`, `patterns/bad/anti-patterns.md`, `DESIGN.md`, `design/ux-decisions/*.md`. Glob `CLAUDE.md` and `AGENTS.md` in the same batch but keep them separate; an agent instructions file is not a Blueprint artifact, and most repos have one without Blueprint.
2. If no Blueprint artifact exists, say so and point at `/blueprint-mode:onboard` or `/blueprint-mode:setup-repo`, whether or not an agent instructions file is present.
3. Read decision frontmatter for status counts and the most recent Active decision in each tree. Count anti-pattern sections by `## ` headings and `DESIGN.md` rules by non-placeholder bullets.
4. Classify the agent instructions file: references Blueprint docs; contains a `Pre-Edit Checklist` heading, which means it was generated by Blueprint 1.x and `/blueprint-mode:onboard` should be rerun; or missing.
5. Show only the sections that exist. A backend repo may have no design tree; that is normal, not a gap.

## Output

```markdown
## Blueprint Status for [project]

### Specs
- product.md, tech-stack.md, boundaries.md: present / missing
- Features: N, NFRs: N

### ADRs
- Active N, Draft N, Superseded N, Deprecated N
- Latest: ADR-NNN "[title]" ([date])

### Patterns
- Good: N, Anti-patterns: N

### Design (only if DESIGN.md or design/ exists)
- DESIGN.md: N rules
- UX decisions: Active N, Draft N

### Agent instructions
- CLAUDE.md / AGENTS.md: current | 1.x checklist (rerun /blueprint-mode:onboard) | missing
```

Close with at most three next actions that matter: Draft decisions to finish, superseded decisions with no code references to delete, a 1.x agent instructions file to regenerate, or the setup skill to run.
